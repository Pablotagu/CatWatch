# CatWatch

REST API for monitoring temperatures inside cat shelters using ESP32 probes with temperature sensors. 
This is a personal learning project built with .NET 10 and ASP.NET Core, currently a single API with Docker support and a test project, designed to grow iteratively into a more sophisticated system while I explore technologies and patterns like DDD, TDD and Azure.
Development is AI-assisted (Claude, GitHub Copilot) used as a senior pair-programmer, not as a code generator. 
All architectural and technical decisions are mine. More details will be added as the project evolves.
