# CatWatch

API REST para monitorización de temperaturas de casetas de gatos, construida con ASP.NET Core 10.

## Requisitos

- [.NET 10 SDK](https://dotnet.microsoft.com/download)

## Ejecutar

```bash
dotnet run --project CatWatch
```

La API queda disponible en `https://localhost:7xxx` (el puerto exacto se muestra en consola).
